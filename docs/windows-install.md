# Nagi for Windows: インストールと更新

Nagi は、ローカルの LLM と辞書で変換する日本語入力です。この文書は Windows 版の導入手順です
（zip の中にも `README.md` として同梱しています）。

- 対象: Windows 10 22H2 以降 / Windows 11（x64 と ARM64。ARM64 版は実機未確認）。ARM64 版は ARM64 ネイティブのアプリでだけ使えます（x64 エミュレーションで動くアプリには Nagi は出ません）
- 状態: **実機での検証が済んでいません**（開発中のプレビュー。`docs/real-hardware-checklist.md` §8）。動作しない・不安定な場合があります
- 実機での検証が済むまで、リリースは prerelease として公開します。その間は方法 A（`irm | iex`）が使えないことがあります。方法 B で取得してください
- 入力内容・個人情報は外部へ送りません。ネットワークを使うのは、辞書・モデルの取得と更新の確認だけです（更新の確認は設定で無効にできます）

## インストール

### 通常はこれ: セットアップ exe（ダブルクリック）

1. [GitHub Releases](https://github.com/shiki-01/nagi/releases) の `windows-vX.Y.Z` から **`Nagi-setup-X.Y.Z.exe`** をダウンロードします（x64 と ARM64 で共通の 1 個です。PC の CPU に合う版が自動で入ります）。
2. ダブルクリックして実行します。「Windows によって PC が保護されました」と出たら、**「詳細情報」→「実行」**を押します（署名していない配布物のため。下の「SmartScreen について」）。ブラウザが「一般的にダウンロードされていません」と警告する場合も、Edge ならダウンロード一覧の「…」→「保存」→「詳細表示」→「保持する」で進めます。
3. ユーザーアカウント制御（UAC）の確認で「はい」を押します（標準ユーザーの場合は管理者のパスワードが要ります）。`C:\Program Files\Nagi` への配置と入力方式の登録に管理者権限が必要です。
4. ウィザードに従って進みます。「辞書とモデルをダウンロードする」（既定でオン、約 150MB）を選ぶと、導入の途中で別に開く窓に進み具合が出ます。失敗しても導入は完了し、完了画面に後から取得する手順が出ます（このセットアップをもう一度実行しても取得できます）。
5. 完了後、下の「インストール後の設定」へ進みます。

更新は、新しい `Nagi-setup-X.Y.Z.exe` をそのまま実行すれば上書きされます（使用中のファイルは名前を変えて退避し、旧版の変換エンジンは止めて入れ替えます）。取得済みの更新を適用する自動更新（下の「更新」）も、そのまま使えます。

削除は、設定 >「アプリ」>「インストールされているアプリ」の「Nagi（日本語入力）」から行います。設定・学習データ・ユーザー辞書・取得した辞書とモデル（`%APPDATA%\Nagi`）は、**既定では残します**（削除するかを確認する画面が出ます）。サイレントでは `Nagi-setup` の `unins000.exe /VERYSILENT /REMOVEUSERDATA=1` のときだけ削除します。

セットアップ exe の配置・登録・スタートメニュー・辞書とモデルの取得は、下の PowerShell 版と**同じスクリプト（`install.ps1`）**が行うので、結果は同じです。

以降は PowerShell を使う方法です（上級者向け・exe が使えない環境向け）。

### 方法 A: PowerShell で 1 行

通常の PowerShell（管理者でなくてよい）で次を実行します。

```powershell
irm https://nagi.shiki-01.com/install.ps1 | iex
```

PC の CPU（x64 / ARM64）に合う最新版の zip を取得し、SHA-256 を確かめてから、同梱のインストーラを実行します。途中で、ユーザーアカウント制御（UAC）の確認が出ます（`C:\Program Files\Nagi` への配置と、入力方式の登録に管理者権限が必要です）。
続けて、辞書とモデルを配布元から取得します（約 150MB。取得済みのものは飛ばします）。辞書だけで使う場合や後で取得する場合は、実行前に `$env:NAGI_SKIP_DATA = '1'` を設定します。

この方法でダウンロードしたファイルには「インターネットから取得」の印（Mark of the Web）が付かないため、SmartScreen の警告は出ません。

### 方法 B: zip を手動でダウンロードする

1. [GitHub Releases](https://github.com/shiki-01/nagi/releases) の `windows-vX.Y.Z` から、x64 の PC は `Nagi-windows-X.Y.Z.zip`、ARM64 の PC は `Nagi-windows-arm64-X.Y.Z.zip` をダウンロードします（CPU が合わない zip はインストーラが配置の前に止めます）。
   - ブラウザが「一般的にダウンロードされていません」などと警告することがあります（署名していない配布物のため。下の「SmartScreen について」）。Edge ではダウンロード一覧の「…」→「保存」→「詳細表示」→「保持する」の順に進みます。
2. **展開する前に** zip を右クリック →「プロパティ」→ 全般タブ下部の「許可する」（ブロックの解除）にチェックして OK を押します。この手順を飛ばすと、展開したファイルすべてに警告の印が付きます。
3. zip を展開します（右クリック →「すべて展開」）。
4. 展開したフォルダで PowerShell を開き、実行します。

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
   ```

   `.ps1` を直接ダブルクリックしても実行されません（既定の実行ポリシーが Restricted のため）。必ず上のコマンドで実行してください。
5. 「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を押します。

インストーラのオプション: `-SkipData`（辞書とモデルを取得しない）、`-Model small|xsmall|none`（取得するモデル。既定は small）、`-InstallDir <パス>`（配置先。既定は `C:\Program Files\Nagi`）。

### インストール後の設定

1. 設定 > 時刻と言語 > 言語と地域 > 日本語 >「…」>「言語のオプション」>「キーボードを追加する」で **Nagi** を選びます。
2. Win+Space（または、タスクバーの入力方式の表示）で Nagi に切り替えます。開いているアプリでは、アプリを開き直すと反映されます。

管理者権限のアカウントと、実際に使うアカウントが別の場合（UAC で別のアカウントの資格情報を入力した場合）は、入力方式の登録が使うアカウントに反映されないことがあります。その場合は、使うアカウントで管理者として PowerShell を開き直し、同じ手順を実行してください。

## 配置されるもの

| 場所 | 内容 |
| --- | --- |
| `C:\Program Files\Nagi\` | `nagi_windows_tsf.dll`（入力方式）、`imserver.exe`（変換エンジン）、`nagi-settings.exe`（設定画面）、`uninstall.ps1`、ライセンス、`VERSION`、`SHA256SUMS` |
| `%APPDATA%\Nagi\data\` | 辞書（`dict\nagi-dict.bin`）とモデル（`models\*.gguf`）。配布元から取得したもの |
| `%APPDATA%\Nagi\` | 設定（`config.toml`）、学習データ、ユーザー辞書 |
| `%ProgramData%\Microsoft\Windows\Start Menu\Programs\Nagi\` | スタートメニューのショートカット（設定・設定フォルダ・ログフォルダ・状態確認） |
| レジストリ | COM の登録（`HKCR\CLSID`）、TSF の入力方式、「アプリと機能」の項目（`HKLM\...\Uninstall\Nagi`） |

Program Files に置くのは、UWP などの保護されたアプリにも DLL を読み込ませるためです。

## 更新

新しい版があるときは、入力方式が起動したときの更新確認（24 時間に 1 回。設定 `[update] auto_check`、無効にできます）で見つけ、**バックグラウンドで取得して署名を検証**します（取得した版は `%LOCALAPPDATA%\Nagi\update` に置かれます）。取得できると右下のトーストが出るので、次のどちらかで適用します。

- スタートメニューの「Nagi」フォルダの「**Nagi を更新**」
- 入力インジケーター（あ / A）を右クリック →「更新を適用（X）…」

ユーザーアカウント制御（UAC）の確認が 1 回出ます。適用では、Program Files 側で署名をもう一度検証してから置き換えます。**サインアウトするか再起動すると**、すべてのアプリで新しい版にそろいます。

この機能を含まない旧版からの更新と、取得に失敗したときは、方法 A のコマンドをもう一度実行します（上書きします）。使用中のファイルは名前を変えて退避されるため、そのまま置き換えられます。Program Files 以外に入れた場合も、自動更新は使えないので方法 A を使ってください。

### 更新を手動で確認する

自動の確認を待たず、好きなタイミングで確認できます（`[update] auto_check` を無効にしていても使えます）。

- 入力インジケーター（あ / A）を右クリック →「**更新を確認…**」
- スタートメニュー → Nagi →「**Nagi 更新の確認**」
- 設定画面（右クリック →「設定…」）の左の一覧の「更新」→「更新を確認」

設定画面の「更新」ページが開いて確認が走り、「最新です」「新しい版 X を取得しました」（リリースノートへのリンクつき）、またはエラーの理由が表示されます。新しい版が見つかった場合は署名を検証して取得まで行い、取得できると「**更新を適用…**」ボタンが出ます（押すと新しいコンソールが開き、UAC の確認のあと適用されます。上の方法と同じ）。確認だけをコマンドで行うこともできます: `imserver.exe --check-update`（結果を 1 行の JSON で出力します）。

自動更新は公開リリース（`prerelease` でないもの）が対象です。確認用の URL で試すには `config.toml` の `[update] check_url` にテスト用の `latest.json` の URL を書きます（手順は `docs/real-hardware-checklist.md` §8.7）。

## アンインストール

「設定 > アプリ > インストールされているアプリ」の「Nagi（日本語入力）」、または次のコマンドで行います。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Program Files\Nagi\uninstall.ps1"
```

- 入力方式の登録解除（`regsvr32 /u`）と、`C:\Program Files\Nagi` の削除をします。使用中で消せないファイルは、再起動時に削除されます。
- 設定・学習データ・ユーザー辞書・取得した辞書とモデル（`%APPDATA%\Nagi`）は**残します**。すべて消すには `-RemoveUserData` を付けます（確認で `yes` の入力が要ります。`-Force` で省略）。学習データだけを消したい場合は、`%APPDATA%\Nagi\learning.tsv` を削除してください。

インストール先には更新の適用スクリプト `apply-update.ps1`（スタートメニューの「Nagi を更新」）と、実機の動作確認用スクリプト `verify.ps1`（クラッシュ復帰・スリープ・環境・パスワード欄の確認。手順は `docs/windows-verification.md`）も置かれます。

スタートメニューの「Nagi」フォルダ（全ユーザー）に、「Nagi 設定」（設定画面。下記）、「Nagi 設定ファイル（config.toml）」（メモ帳で開く）、「Nagi 設定フォルダ」（`%APPDATA%\Nagi`）、「Nagi ログフォルダ」（`%LOCALAPPDATA%\Nagi\logs`）、「Nagi 状態確認（verify）」（`verify.ps1 status` を新しいコンソールで実行）、「Nagi 更新の確認」（設定画面の更新ページを開いて確認を実行。「更新」の節）、「Nagi を更新」（取得済みの更新の適用。「更新」の節）のショートカットが作られます（アンインストールで削除。作れなくてもインストールは成功します）。入力インジケーターのメニューに頼らずに設定を開けます。

タスクバーの入力インジケーター（あ / A）を右クリックすると、設定（`config.toml`）・設定フォルダ・ユーザー辞書フォルダ・ログフォルダを開く項目と、「状態を確認（verify.ps1）」（`verify.ps1 status` を新しいコンソールで実行）が出ます。一番上の「設定…」が設定画面です。

## 設定の開き方（設定画面）

次のどちらかで開きます。

- タスクバーの入力インジケーター（あ / A）を右クリック → **設定…**
- スタートメニュー → Nagi → **Nagi 設定**

`nagi-settings.exe` が起動し、「Nagi 設定」というウィンドウが開きます（ブラウザは使いません。通信もしません）。左の一覧でカテゴリを選び、右で項目を変えると、すぐ `config.toml` に保存されて反映されます（コメントや他の項目は保たれます）。起動直後は変換エンジンを起動して設定を読み込むため、「読み込み中…」と表示されることがあります。

- 左下の「詳細設定を表示」で、表示する項目を切り替えられます。「既定に戻す」でその項目の明示指定を消せます。
- 「（再起動後に反映）」と書かれた項目は、入力方式を切り替え直すか、アプリを開き直すと反映されます。
- 値が範囲外などのときは、その項目の下に赤字でエラーが出て、保存されず元の値に戻ります。数字は全角でも入力できます。空欄にすると既定に戻ります。
- 「データ・ファイル」ページで、`config.toml`（メモ帳）・設定フォルダ・ユーザー辞書フォルダを開けます。「学習データを全削除…」は確認のあとに学習内容をすべて消します（ユーザー辞書は消えません）。「更新」ページは上の「更新」の節のとおりです。
- ウィンドウを閉じる（右上の×、または Esc）と、設定画面のプログラム（と、その裏のエンジン）が終了します。すでに開いているときにもう一度「設定…」を選ぶと、開いているウィンドウが前面に出ます。
- 開けないとき（`nagi-settings.exe` が無い場合は「設定…」が灰色です）は、`config.toml` を直接編集できます。ユーザー辞書の管理画面はまだありません。
- 言語の設定からも開けます（`ITfFnConfigure`。0.1.17 の実機では未確認。表示されない環境があります）。
  - Windows 11: 設定 → 時刻と言語 → 言語と地域 → 日本語の「…」→ 言語のオプション → キーボードの「Nagi」の「…」→ キーボード オプション
  - 旧来の画面: `Win+R` で `rundll32.exe shell32.dll,Control_RunDLL input.dll,,{C07337D3-DB2C-4D0B-9A93-B722A6C106E2}` →「テキスト サービスと入力言語」→ Nagi を選んで「プロパティ」
- 従来のブラウザ版は `nagi-settings.exe --web` で開けます（ローカルの `127.0.0.1` だけで動きます）。

## SmartScreen について

この配布物は Authenticode（コード署名）で署名していません。署名の証明書は有償で、現時点では用意していないためです。そのため、ブラウザなどでダウンロードした zip や実行ファイルには、Microsoft Defender SmartScreen が「一般的にダウンロードされていません」「Windows によって PC が保護されました」と警告することがあります。

- 方法 A は、警告の原因になる印が付かない取得方法です。配布元（`nagi.shiki-01.com`・GitHub）と HTTPS を信頼できる場合に使ってください。
- 方法 B で警告が出る場合は、上の手順（zip のブロック解除、または「詳細情報」→「実行」）で進められます。ファイルの正しさは、zip と同時に公開している `latest.json` の SHA-256 と照合できます。

  ```powershell
  (Get-FileHash .\Nagi-windows-X.Y.Z.zip -Algorithm SHA256).Hash
  ```
- ソースコードは公開しています。自分でビルドすることもできます（手順は `.github/workflows/windows-release.yml` が参照になります）。

将来の方針（署名の導入）は `docs/decisions.md` H-42 にあります。

## うまくいかないとき

- **入力方式に Nagi が出ない**: サインアウトして入れ直す。`regsvr32` の登録が失敗していないか、管理者の PowerShell で `regsvr32 "C:\Program Files\Nagi\nagi_windows_tsf.dll"` を実行して確かめる。
- **変換されず読みがそのまま出る**: 辞書が無い状態です。方法 A をもう一度実行するか、`"C:\Program Files\Nagi\imserver.exe" --install-data --data-dir "$env:APPDATA\Nagi\data" --model small` を実行して辞書とモデルを取得します。
- **`imserver.exe` が起動しない**: Visual C++ 再頒布可能パッケージを入れる（[x64](https://aka.ms/vs/17/release/vc_redist.x64.exe) / [ARM64](https://aka.ms/vs/17/release/vc_redist.arm64.exe)）。
- **エンジンが停止した通知が出る**: 自動で再起動します。繰り返す場合は `imserver.exe` を端末から直接実行して、エラーの内容を確かめてください。
